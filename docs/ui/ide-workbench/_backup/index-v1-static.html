GoGo IDE 工作台 · 高保真 UI 设计稿

目标：左侧 openvscode-server（VSCode Web 文件树 + 编辑器），右侧 AI 对话面板（仅 deepseek-harness · 标识 main），整体对齐 Cursor / Trae。下方为两个变体，均基于真实 GoGo 布局与工作区结构绘制。

设计假设与推理： ① 保留 GoGo 全局壳（顶栏 + 侧栏），IDE 工作台作为 #/ide 页面渲染进内容区，随时可切回其它页面； ② 左侧为 openvscode-server 嵌入区（真实实现为 iframe，挂载 D:\Myproject\GoGo 到容器 /home/workspace），文件树即工作区真实结构； ③ 右侧对话面板固定 360px，会话固定复用 agentId='main'（deepseek-harness）； ④ 签名元素：面板顶部「引擎状态 · 智能体身份」复合条（绿点运行中 + 角色名 + main 徽标 + 工作区路径），以及可折叠的「思考中」块——AI 透明性贯穿两变体； ⑤ 变体 A 贴合 GoGo 现有浅色视觉（编辑器深色形成对比）；变体 B 为 Cursor / Trae 式整体深色。
